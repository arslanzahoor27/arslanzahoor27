## 🚀 Featured Projects

| Project | Description | Tech |
|---|---|---|
| **[AI Career Recommendation System](https://github.com/arslanzahoor27/AI-Career-Recommender)** | Content-based career recommender matching skills to roles via TF-IDF and cosine similarity across 51 job roles and 233 distinct skills. Ranked skill-gap analysis, exportable PDF reports, and a monochrome editorial Streamlit frontend. | Python, Scikit-learn, Streamlit, ReportLab, Pandas |
| **[Credit Scoring Model](https://github.com/arslanzahoor27/CodeAlpha_Credit-Scoring-Model)** | ML model trained on real-world financial data to predict loan approval, with an interactive Streamlit web app. | Python, Scikit-learn, Streamlit |

| **[Data Classification using AI](https://github.com/arslanzahoor27/data-classification-using-ai)** | End-to-end supervised ML pipeline covering preprocessing, feature engineering, training, and evaluation. | Python, Scikit-learn |
| **[Voting System Project](https://github.com/arslanzahoor27/Voting_System_Project)** | GUI-based virtual voting system with authentication, vote management, and result generation. | C++ |

<br>

- Ingests 51 job roles, each mapped to a `skills_text` field spanning 233 distinct technical skills
- Vectorizes skills with **TF-IDF**, ranks role fit via **cosine similarity**
- `CareerRecommender.recommend(skills_list)` returns ranked matches with a skill-gap breakdown
- Frontend: a monochrome, editorial-style Streamlit app, not a stock Streamlit demo
- Exports a shareable PDF report via ReportLab

<br>

- Runs entirely in-browser using **MediaPipe Hands** for real-time hand landmark tracking
- **p5.js** renders gesture-triggered visual effects on top of the camera feed
- No install, no backend: point a browser at it and the hand becomes the input device
